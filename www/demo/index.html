브라우저로 확인할 수 없는 것

malformed 요청은 브라우저가 막거나 자동으로 고칩니다. 프로젝트 루트에서 sh tests/raw.sh 8080을 실행하면 요청 줄을 직접 입력할 수 있습니다. 

sh tests/raw.sh 8080
curl -i http://localhost:8080/demo
curl -i -H 'Range: bytes=0-4' http://localhost:8080/demo/index.html
printf 'GET / HTTP/1.1\r\n\r\n' | nc -w 3 127.0.0.1 8080

서버 실행: ./server 8080 ./www ./cgi-bin

504를 보려면 --timeout 1로 실행하세요.
